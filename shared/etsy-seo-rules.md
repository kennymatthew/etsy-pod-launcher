# Etsy SEO Rules (reusable across all projects)
**Last updated:** 2026-05-31

---

## Title
- Max 140 characters — use all of them
- Put highest-intent keywords first (Etsy weights beginning of title)
- Use comma-separated keyword phrases
- Can include brand names (e.g., Comfort Colors®) if using that blank
- Don't use all caps for entire title — first word in caps is fine

## Tags
- 13 tags max, 20 characters each
- Use multi-word phrases — they match exact buyer search queries
- First 3 tags carry most algorithmic weight
- Repeat your most important title keywords as tags
- Update tags after 30 days using Etsy Stats → Search Terms

## Description
- First 160 characters show in Google search snippets — make them count
- Etsy does NOT index descriptions for search — they're for conversion, not SEO
- Use bullet points and emoji headers for scannability
- Always include: sizing, materials, how to order, shipping time

## Photos
- 10 photos max — use all of them
- First photo = thumbnail = most important (lifestyle shot beats flat lay)
- Include size chart as one photo
- Include mockup on model for scale reference
- Video increases conversion (Etsy shows video in search now)

## Pricing & Sales
- Etsy promotes listings with active sales in search
- Free shipping (built into price) gets a search boost
- Etsy Star Seller badge requires: 95%+ 5-star reviews, <24hr reply time, on-time dispatch

## Listing Refresh
- Edit a listing (even minor change) to signal activity to Etsy algorithm
- Renew manually if listing expires (avoid auto-renew if not selling)
- Run seasonal sales aligned with wedding season (Jan–June peak)
